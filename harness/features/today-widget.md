# 今日日程小组件 · P0 规格

状态：agreed（2026-11-19；v0.11：取消 DWM 亚克力，不透明度改为背景层对桌面的真实 Alpha 合成；v0.10 同日修订：不透明度 100% 时背景实色完全不透出桌面；v0.9：「无」优先级占位显示灰色「无优先级」；v0.8：输入框默认无描边、点击即默认低优先级、日期 chip 仅编辑态渐入、占位文案随优先级着色并提亮；v0.7：移除优先级滑块改由输入框边框表意、占位文案三态、最小高度 320、卡片圆角 10、「已完成」间距收紧、设置窗口自绘滑块与开关圆球填满）
基准尺寸：331 × 454（默认）；可缩放范围 300 × 320 ～ 662 × 908

## 1. 结构

```
┌─────────────────────────────────┐  331，左右边距 20
│ 今天 ▾                      ⋯   │  标题行 40
│ ┌─────────────────────────────┐ │
│ │ 添加任务              📅今天 │ │  输入框 38（1–5 行）
│ └─────────────────────────────┘ │
│ □ 可视化修改-3（后端）      今天 │  任务行 40
│ ┌ 今天 ───────────────────────┐ │  日期分组标题 36（仅「所有」视图）
│ ⌄ 已完成                     1 │  分组标题 28
│ ☑ 校园网助手申请软著        今天 │  已完成行 40
└─────────────────────────────────┘  454
```

- 背景：**单独一层**背景色（`Bg.Widget` 中性深灰实色，默认 100% 不透明，窗口不开亚克力），圆角 10；不透明度只改这一层，降低时真实透出桌面，文字、边框、弹层永不跟随变透明。
- **窗口四周无白色/亮色外描边**，圆角外为完全透明。
- 窗口默认 331 × 454，可拖动任意一边或任意一角自由缩放；**最小 300 × 320**，最大 662 × 908。缩放只重排版式（列表更高/更宽、滚动条自适应），**字号不随窗口缩放**。
- 左右内容边距统一 20，行内左右再留 6，使最左复选框与最右日期距卡片边缘完全一致。
- 标题行：左「今天 ▾」（17 SemiBold，可点击切换视图），右「⋯」（32×32，三点水平居中）。
- 输入框：**无前置图标**，占位「添加任务」（`Text.Secondary`，不加透明度衰减）；**空闲无描边**，点击进入编辑态后默认低优先级，**边框颜色即当前优先级**（低/中/高为对应实色）；日期 chip 仅编辑态渐入显示。
- 任务行：复选框（18，圆角 5，描边色=优先级）+ 标题（15）+ 右侧日期（13，`Accent`），三者同一条水平线垂直居中。
- 已完成分组：标题「已完成」+ 数量；行内复选框灰色填充 + 白色对勾、标题删除线、日期 `Text.Secondary`。
- 所有弹层（视图菜单、更多菜单、日历、设置窗口、详情面板、斜杠菜单）一律 **100% 实色** `Bg.Surface`（`#FF26272A`），不透出桌面。

## 2. 输入框状态机

| 状态 | 触发 | 表现 |
|---|---|---|
| Idle | 初始 / 收起编辑 | 高 38（圆角 11），**无描边**，占位「添加任务」，日期 chip 隐藏 |
| Editing | 点击输入框区域 | 默认切到 **低优先级**（仅边框体现）；占位仍为「按Tab切换优先级」（中性色）；日期 chip 160ms 渐入 |
| Priority set | 编辑态按 `Tab` | **首次按下直接到「高」**，之后按 高 → 中 → 低 → 无 → 高 循环；占位改为「低/中/高优先级」并着色；「无」显示「无优先级」（灰 `Priority.None`） |
| Multiline | 文字换行 | 高度随行数增长（38 / 58 / 78 / 98 / 118）；日期 chip 让位到第 2 行并保持右对齐 |
| Submitting | Enter | 提交任务，清空文字、高度回落 38、优先级回到「低」、保持焦点 |

- 退出编辑：**优先级还原为「无」**，描边与日期 chip 180ms 过渡回无状态（chip 渐隐）；下次点击重新从「低」开始。
- **只有点击输入框区域才进入编辑态**。点击卡片其他区域（标题行、任务行、已完成分组、空白处）一律退出编辑态，日期弹窗同时收回。
- 选中日期（快捷行/确定）后输入框保持编辑态并恢复焦点，不收起。
- ESC：先关日历；再按 ESC 退出编辑态。
- 失焦（点击桌面或其他窗口）退出编辑态；日历弹窗打开期间不退出。

## 3. 优先级

- **不再有优先级滑块/弹层**：优先级只用输入框边框颜色表达，标题行不再被覆盖。
- **进入编辑态即默认低优先级**（用户明确要求），无需额外操作。
- 交互：`Tab` 顺序为 **高 → 中 → 低 → 无 → 高**；**本次编辑第一次按 Tab 直接到「高」**（不接着默认「低」往下走），`Shift+Tab` 反向（首次为「无」）；**不拦截数字键**，`1`–`4` 正常输入。
- 输入为空时：**未按过 Tab 前**占位固定为「按Tab切换优先级」（`Text.Secondary` 中性色）；按过 Tab 后显示当前优先级（「低优先级」/「中优先级」/「高优先级」/**「无优先级」**），且**文字颜色与优先级一致**；「无」用灰色 `Priority.None`。
- 提交后优先级回到「低」并重置提示态（占位回到「按Tab切换优先级」），输入框保持焦点；**失焦退出编辑态时优先级还原为「无」**。

## 4. 颜色映射

| 优先级 | 输入框描边 | 占位文字 | 复选框描边 |
|---|---|---|---|
| 无 | 无（透明） | `Priority.None`（灰，「无优先级」） | `Priority.None` |
| 低 | `Priority.Low` | `Priority.Low` | `Priority.Low` |
| 中 | `Priority.Medium` | `Priority.Medium` | `Priority.Medium` |
| 高 | `Priority.High` | `Priority.High` | `Priority.High` |

只改描边与占位文字颜色。任务文字、日期 chip 颜色不变。强调色跟随主题：Plana `#B49AF0` / 经典蓝白 `#5C8DFF`。

## 5. 自适应高度

- 单行 38px；每增一行 +20px（38 / 58 / 78 / 98 / 118，上限 118）。
- 内边距上下各 9px，行高 20px。
- 换行规则：按可用宽度自然折行，不出现横向滚动。
- 高度变化 120ms 动画。
- 文字增高时操作行始终跟在文字下方（不得挤在右侧）。

## 6. 提交规则

- Enter：提交。Shift + Enter：换行。
- 空内容（含纯空格）Enter：不提交、不提示、不震动。
- 提交后：任务插入当前视图列表顶部；输入框清空并保持焦点；优先级回到「低」；日期沿用当前草稿日期。

## 7. 日期 chip 与日历

- chip **仅编辑态显示**：进入编辑态 160ms 渐入，退出 160ms 渐隐；隐藏时不可点击且不占位（`IsHitTestVisible=False`）。无下拉箭头；文案：今天 / 明天 / 后天，更远显示 `M月d日`，跨年显示 `yyyy年M月d日`。
- 点击 chip 任意位置：在 chip 下方弹出日历（宽 272，圆角 12，`Bg.Surface`，阴影），自上而下：
  1. 快捷行：今天 / 明天 / 后天 / 清除。
  2. 月份行：`2026年11月` 左对齐；右侧 `‹`、`⊙`、`›` 三个按钮间距 8。
  3. 星期行：**周日起始**，日 一 二 三 四 五 六。
  4. 42 格日期（前后月补位淡化）。
  5. 按钮行：`确定`（`Accent` 实心）+ `清除`（深色底）。
- 选中日：30 × 30 蓝色实心圆 + 白字；今天（未选中）：蓝色文字。
- 点日期：仅在面板内选中并同步 chip，不关闭；点「确定」应用并关闭，**输入框不收起**。
- 快捷行 / 「清除」：立即应用并关闭，输入框保持编辑态。
- P0 不含时间、提醒、重复。

## 8. 任务行交互

- 行高 40；**整行 hover**（`Bg.Hover`，行容器强制横向拉伸）；标题与日期同为 20px 行高，垂直居中后基线视觉齐平。
- **复选框独立 hover，仅包裹 18×18 框**：填充 `Bg.Selected` 并放大 1.12 倍，与整行 hover 互不替代。
- **只有点复选框才勾选**；点标题（含已完成行）打开任务详情面板。
- 勾选动画（约 0.38s）：复选框变实色并弹出白色对勾 → 删除线**从左向右生长**（1.2px 覆盖线，`scaleX 0→1`，200ms）→ 标题变灰 → 整行高度收 0、右移淡出；动画结束才写回仓储。
- 已完成行点勾：直接恢复，不播放收起动画。
- 右键：P1。
- 已完成分组默认折叠，标题显示数量；标题整行 hover、高 36、内边距 6；展开箭头向下。
- 点击任务行不会进入输入框编辑态。

## 9. 视图切换（新）

- 点击左上角标题打开下拉菜单（`Bg.Surface`，圆角 12，200ms 内关闭）：所有 / 今天 / 明天 / 最近7天，左侧图标、右侧当前项对勾。
- 标题文案随视图变化：所有 / 今天 / 明天 / 最近7天。
- 数据范围：
  - 今天：仅今天；
  - 明天：仅明天；
  - 最近7天：今天起 7 天内（含已完成）；
  - 所有：全部任务。
- 「所有」视图按日期分组，顺序：今天 → 明天 → 后天/其他日期升序 → 「已完成」固定最下方；组标题 34 高、13 SemiBold、`Text.Secondary`，带展开箭头。
- 非「所有」视图只有一个无标题分组，避免重复日期标题。

## 10. 更多菜单与设置窗口（新）

- `⋯` 按钮 32 × 32，三点水平居中，右缘与卡片 20 边距对齐，垂直与标题同高；hover `Bg.Selected`。
- 点击打开菜单（164 宽，实色）：「设置」。
- 设置是**独立无边框窗口**（**440 × 600**，圆角 12，阴影；**浅色单一主题**，白底 `Settings.Surface`），打开时贴在小组件左侧；左侧放不下翻到右侧，纵向与小组件顶部对齐。
- 标题栏高 56，左「配置桌面小部件」17 SemiBold，右 × 关闭；整条可拖动，`Esc` 关闭。
- 内容为三组「灰卡片」，无分隔线，每组上方 15 SemiBold 组标题：
  1. **主题与样式**：主题=深色⌄；不透明度=**自绘滑块**（轨道 4px 圆角，188 宽，已填充段为品牌蓝；小球 14px 蓝色实心圆，随值移动；值域 40–100，无百分比文本）。
  2. **分组排序**：分组=时间⌄；排序=时间⌄；顺序=从旧到新⌄。
  3. **小部件显示**：置于顶层 / 显示添加输入框 / 显示已完成（蓝色胶囊开关 40 × 22，**白色圆球 22 × 22 上下刚好填满胶囊**）；日期显示为=任务时间⌄。
- 行高 56，左右内边距 18；标签 15 深色，值 15 次要色，值后带 9 × 6 下箭头；组标题 16 SemiBold。
- 生效规则：不透明度**只作用于背景层**，文字、边框、弹层始终保持不透明；置于顶层即时改 `Topmost`；显示添加输入框隐藏整个录入区；显示已完成隐藏「已完成」标题与列表。四项均写入 `settings.json`。
- 拖动滑块实时预览，释放时落盘；开关即时落盘。

## 11. 分组与滚动条

- 滚动条为**覆盖层**：ScrollViewer 自身滚动条隐藏，右侧叠加 14px 透明轨道 + 6px 圆角灰条（`Scroll.Thumb`，hover 提亮），不占布局宽度；展开已完成或行数变化时内容宽度不位移。
- 滑块高度按视口比例计算（最小 30），支持拖动滑块、点击轨道跳转、在轨道上滚轮滚动。
- 列表纵向滚动，横向禁用。

## 12. 任务详情面板（440 × 330）

- 独立无边框窗口，**弹在小组件左侧或右侧**（右侧优先，右侧放不下翻到左侧，两侧都不够时贴工作区边缘），纵向与小组件顶部对齐并夹在工作区内；层级在小组件之上。
- 点击其他窗口或 ESC 关闭。
- 顶部（高 48，左右 18）：18 复选框 + 1px 竖分隔 + 日历图标与「11月17日, 今天」（`Accent`，13）；右侧 18 优先级圆环（点击循环 无 → 低 → 中 → 高 → 无）。各元素间距 12。
- 标题：17 SemiBold 无边框输入，实时写回仓储。
- 内容：Markdown 纯文本编辑区（13px / 行高 21），左右 24，实时写回，占位「添加描述…」。
- `/` 快捷插入：输入 `/` 时菜单出现在**光标右侧**（`caret.Right + 6`，行下方 4px），宽 196，最大高 292；菜单打开期间点击菜单项不得关闭详情面板；选择后删除 `/` 并插入对应 Markdown 前缀（行内项不换行）。
- 底部（高 46，左右 18）：左「收集箱」chip；右侧 `Aa` / 评论 / 更多 图标。
- 面板整体中性深灰，不使用偏蓝色底。
- P0 不渲染 Markdown 富文本，不接真实附件与关联。
