# 月历小组件 · P0 规格

状态：implementing（2026-11-19，取消 DWM 亚克力，改为真实 Alpha 透明）
更新时间：2026-11-19
基准尺寸：662 × 544（默认）；可缩放范围 530 × 436 ～ 1324 × 1088

## 1. 结构

```
┌──────────────────────────────────────────────────────────┐  662，左右边距 16
│ ▣ 2026年11月 ⌄             ＋  月⌄   ‹ 今天 ›   ⋯       │  标题行 44
│  周日    周一    周二    周三    周四    周五    周六      │  星期行 28
│ ┌──────┬──────┬──────┬──────┬──────┬──────┬──────┐        │
│ │25 十六│26 十七│…     │      │      │      │31 万圣夜│      │  6 × 7 网格
│ │[任务条]      │      │      │      │      │      │        │  自适应多条 + +N
│ ├──────┼──────┼──────┼──────┼──────┼──────┼──────┤        │
│ │…                                               │        │
│ └──────┴──────┴──────┴──────┴──────┴──────┴──────┘        │
└──────────────────────────────────────────────────────────┘  544
```

- 背景：独立 `Backdrop` 层承载 `Bg.Widget` 实色（窗口不开亚克力），圆角 16，不透明度仅作用于背景层（40–100%），降低时真实透出桌面。
- 窗口无边框，可拖动标题行或卡片空白处移动；四边 6px、四角 14px 透明热区可自由缩放；缩放只重排版式与单格任务条容量，字号固定。
- 默认停在工作区右上角（距顶 32、距右 32），首次启动若今日组件也在默认右上角则停在今日左侧相距 16。位置、尺寸、不透明度、置顶、显示已完成、显示农历均写入 `settings.json` 的 `Month` 段。
- 标题行左：18 × 18 日历线性图标 + 8 间距 + 可点击年月按钮 `2026年11月 ⌄`（17 SemiBold）。
- 标题行右（间距 8）：`月⌄` 62 × 32 → `‹ 今天 ›` 112 × 32 → `⋯` 32 × 32（移除重复的 `+` 新建按钮，点击任意日期即可新建）。控件圆角 8、`Stroke.Widget` 描边、hover `Bg.Hover`。
- 星期行：周日起始，`周日`…`周六`，12px、`Text.Secondary`、居中。
- 网格：固定 6 行 × 7 列，共 42 格；格线 1px `Divider`；前后月补位日期显示但内容降为 45% 不透明度。

## 2. 单元格与任务条

- 内边距 `6,4`；首行左「日」右「农历/节气/节日」（若设置关闭「显示农历与节日」则隐藏右侧标签）。
- 日号：13px，居中对齐；某月 1 日显示 `11月1日` / `12月1日`，其余只显示数字。
- 今天：日号置于 24 高圆角胶囊（最小宽 24）`Accent` 实心底 + 白色居中文字，单元格额外叠加 `Accent.Soft` 柔底高亮；选中日叠加 `Bg.Selected` 柔底，但**选中态只跟随当日日程浮层的开合**——浮层关闭/点击浮层外区域/失焦收起后高亮立即消失，不会残留灰底。
- 农历/节气/节日：11px 右对齐；节日/节气用 `Calendar.Festival` 绿色；农历初一显示月份名；优先级 节日 > 节气 > 农历。
- **自适应多行任务条**：
  - 按单元格实际可用高度动态计算每格可见任务条数，并预留完整行高，保证最后一条不被底边格线裁切。固定开销 = 格线 1 + 上下内边距 4+4 + 日号行 24 + 芯片上间距 2 = 35；芯片行距 = 16 + 2 = 18。默认 544 高度：5 行月份每格 3 条、6 行月份 2 条；缩到最小 436：5 行月份 2 条、6 行月份 1 条；放大后最多 5 条。
  - 任务条：高度 16、圆角 4、纯色语义柔底（`Month.Chip.*`，不加左侧竖线）、11px 单行省略文字、悬停显示完整任务标题 Tooltip。
  - 已完成任务（开启「显示已完成」时显示）：置灰半透明底 + 淡化删除线。
  - 溢出：超出可视容量时，末行右侧折叠显示 `+N`（`Bg.Selected` 底、`Text.Secondary` 字）。
- 所有浮层（快速新建、视图菜单、更多菜单、年月选择器、当日日程浮层）均采用小组件窗口内嵌动画浮层（160ms 淡入+轻位移），避免独立透明 Popup 窗口出现黑角残影与焦点闪烁。
- 点击任务条直接打开 `TaskDetailWindow`（右侧优先、左侧兜底，与小组件同级）；点击日期空白或 `+N` 选中该日期并弹出**当日日程浮层**，浮层关闭后选中高亮同步清除。

## 3. 当日浮层卡片（贴边悬浮日程与新建）

- 点击任意日期单元格或 `+N` 在格旁伸出深色圆角 `Bg.Surface` 卡片（312 宽，圆角 12；优先向右贴边伸出，右侧空间不足时贴左伸出，不溢出小组件边界）：
  - 顶部条：日期+农历标题，右侧优先级圆点（支持点击与 `Tab` 循环切换优先级并即时上色，不使用旗帜）与关闭按钮。
  - 新建区：标题输入框 + 右侧「待办事项」切换图标（支持普通描述与可勾选子待办双向互转；待办模式 `Enter` 下增一项，空行 `Backspace`/`Delete` 删除）；底部清单切换胶囊（收集箱/欢迎）+ 保存。
  - 当日任务列表（有任务时紧接其下可滚动展示）：每行含复选框、标题（含子待办时带饼状进度图标）、清单名与悬停删除按钮。

## 4. 头部与快捷交互

| 控件 / 操作 | 行为 |
|---|---|
| `2026年11月 ⌄` | 打开**年月选择器弹层**（`< 年份 >` + 1–12 月 4×3 网格，本月蓝点标记），点击月份立即跳转并播放 180ms 动画 |
| `‹` / `›` / 滚轮 / `←` `→` | 上/下一月；网格 180ms 淡入 + 12px 水平位移（连续操作只保留最后一次） |
| `今天` / `T` | 回到今天所在月份并定位今天；今天格自带 `Accent`/`Accent.Soft` 高亮，不额外叠加选中灰底；已在本月仅定位今天，不重播翻月动画 |
| 点击日期格 | 在日期旁伸出深色快速新建与日程卡片（自动避让左右边界），支持优先级旗帜与待办事项 |
| `月⌄` | 打开视图菜单（当前含「月 ✓」，清晰标示月视图） |
| `⋯` | 打开更多菜单 →「设置」，弹出浅色 `WidgetSettingsWindow`（支持不透明度 40–100% 实时作用于背景层、置于顶层、显示已完成、显示农历与节日） |

## 5. 数据与日历算法

- 网格范围：本月 1 日所在周（周日）起 42 天；`DateOnly` 按本地日期比较。
- 任务查询：按 42 天范围查询共享 `ITaskRepository`（随「显示已完成」开关决定 `IncludeCompleted`），同日内按未完成优先 → 优先级降序 → 创建时间倒序排列。
- 农历/节气/节日：复用 `LunarCalendar`（`ChineseLunisolarCalendar` 1901–2100 + 24 节气 + 公农历节日）。
