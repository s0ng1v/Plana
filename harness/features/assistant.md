# 助理 · 助理阶段规格（用户视角）

状态：planned（2026-11-21）
更新时间：2026-11-23
对应：product.md §5、ADR-0042、ADR-0043
原则：本文只写「用户看到什么、能做什么」。技术方案在 Trellis 任务的 design.md。

## 1. 总体约定

1. 助理不打开时，Plana 与现在一样轻（constitution 第 13 条）。
2. 助理只提方案；用户点「应用」才写入。写入后可整批撤销（`Ctrl+Z` 或 Toast「撤销」）。
3. 数据、记忆、画像全部存本机；模型使用用户自己配置的 API（见 model-settings.md）。
4. 未配置模型时，助理面板只显示「先配置模型」引导并直达设置页，其余功能（如自然语言日期）不受影响。

## 2. 输入框理解中文日期（A1）

- 范围：今日小组件输入框、任务页行内添加、日历/月历/四象限的新建卡片。
- 输入「下周三交周报」「后天下午开会」「月底前续费」时，日期 chip 自动变为对应日期，标题里的日期词被移除（`交周报`）。
- 用户手动改过日期 chip 后，不再自动覆盖。
- 设置 → 通用：「自动识别日期」开关，默认开。
- 无法识别时不报错，不改动。
- 完全离线，不调用模型。

## 3. 助理入口与对话页面（A4；样式于 A0–A2 后先行预览，ADR-0044）

- 入口：主窗口左侧导航栏动态 Lana 头像按钮（`LanaAvatarControl`，ADR-0066）、`Ctrl+J` / `Ctrl+4`；点击进入独立对话页面（`MainPage.Assistant`）。后续 A4 在任务/日历/四象限页叠加幽灵预演时提供侧边联动。
- 左栏与对话页 Lana 形象（ADR-0066 / ADR-0068）：
  - 状态统一同步：不在对话页 Sleep，进入对话页 Idle，输入框聚焦 Listening（柔焦弥散呼吸光晕），生成中 Thinking，正常回复完成 Happy（约 2s 后自动回落；停止或报错不触发庆祝）；悬停可唤醒 Sleep / 轻眨眼，点击有果冻回弹；仅对话舞台活体 Lana 在唤醒态支持全窗鼠标视线跟随，左侧导航栏 Lana 不随鼠标移动。
  - 对话页舞台演进：画布中仅存在唯一活体 Lana；空态居中待机（108×108）→ 发送首条消息后欢迎语柔淡，活体 Lana 平滑飞向首条回复左侧（42×42）并切入 Thinking，待其基本就位后「Lana 正在思考…」文字以约 240ms 自左向右轻柔显现 → 后续每轮新消息活体 Lana 平滑滑落至最新回复左侧，原回复左侧柔和留下一枚零开销静态缓存 Lana 静影（`Opacity=0.82`）→ 点击「新对话」平滑浮回居中欢迎位；历史会话切换与滚动时即时贴合；不可见、滚出视口或 Sleep 收敛后彻底停止帧循环，助理未打开时零渲染开销；「减少动效」开启时退化为静态帧与即时落位。
- 对话页面布局：左侧可平滑折叠会话历史栏（236 ↔ 0）+ 居中大厂级对话画布（顶部模型胶囊、活体 Lana 舞台与实时时间问候、流式输出与纯文字流光思考、工具进度胶囊、变更清单预览卡片、底部浮动胶囊多行输入框）。
- 对话：流式输出；可停止生成；可复制/重试；可新开会话；**切换历史会话或新建对话不会中断后台正在干活的 Lana，各会话独立并发执行，侧栏对后台运行中的会话展示轻转圈指示**；新会话首条消息与主回复**并行自动生成**简洁会话标题，互不阻塞；保留最近 30 次会话历史，可删除；工具调用执行中左侧显示转圈圆圈动画，完成后切换为 `✓`；Markdown 表格按列宽比例自动换行、行高自适应且无横向滚动条。
- 日程同步/提案卡片（ADR-0055 / ADR-0057）：日期采用「月+日」形式（如 `明天 (11月22日) 09:00`）；Lana 自动识别具体时间（默认提前 10 分钟提醒）并自动判别任务优先级；每条任务行内可直接点选下拉调整优先级与提醒（提前任意时间、反复提醒），点击即生效、无需确认按钮；不展示解释点击方式的冗余提示文字。对于单条明确新建指令仍直接执行；涉及附件整理或多天/多步骤计划时，Lana 先以「Lana 打算这样安排……」说明方案并征询用户同意，确认后再实际写入。
- 附件：拖入或粘贴图片、截图、PDF、Word（`.docx`）、Excel（`.xlsx`）、PowerPoint（`.pptx`）、HTML/网页、日历（`.ics`）、EPUB/RTF、结构化数据与主流代码/文本文件；单条消息最多 5 个、单个 ≤ 20MB；输入 `@` 可精准引用当前输入框内已添加的图片或文件；仅发送附件未填写文字时默认向 Lana 询问整理建议与安排计划，确认后再写入；格式/容量等提示通过顶部 Toast 通知展示，不常驻占位。
- 能力示例：重排本周未完成任务；把一个目标拆成周计划；按农历/节假日/调休推算日期；把会议纪要或课程表图片整理成任务。

## 4. 幽灵预演（A4 · 已取消，ADR-0049）

- 经 ADR-0049 裁定取消跨页幽灵虚线预演；日程改动与细粒度撤销（单条 / 多选 / 整批）统一在 Lana 对话页面的日程改动卡片及主窗口顶部 Toast 中完成。

## 5. 我的规则（A5）

设置 → 助理 → 我的规则：

- **硬性上限**：每天最多任务数；每天「高优先级」最多几件；休息日（周几）；周末与法定节假日不排指定清单（多选清单）。
- **偏好**：自然语言文本框，如「写作类放上午」。
- **权限分级**：按操作类型选择「直接执行 / 先问我」——拆子待办、归类清单、改期、批量顺延、改优先级、删除。默认：拆子待办与归类直接执行，其余先问我；删除永远先问我，不可改为直接执行。

## 6. 记忆与画像（A5）

- 聊天中出现长期信息时，助理记下并提示「已记住：…  · 撤销」。
- 设置 → 助理 → 助理的记忆：
  - 记忆条目列表：内容、来源（哪次对话）、时间；可编辑、删除、手动添加。
  - 我的画像：可阅读和编辑的文档（作息、常做的事、高效时段、易拖延类型），按记忆与本地完成统计定期更新；每次自动更新前保留上一版。
  - 「打开文件夹」「一键清空」「关闭记忆」。
- 周复盘：每周日晚或用户随时点击生成；展示本周完成数、各清单分布、效率时段、被推迟最多的任务，并给 1–3 条可「一键采纳」的建议（加入规则或画像）。

## 7. 日常小帮手（A6 · 仅保留早安提示，ADR-0049）

- **逾期任务与早安提示（ADR-0059 更新）**：今日小组件不再显示顶部早安横幅，改为在列表顶部直接列出「已过期」未完成任务并提供一键「顺延到今天」按钮；主窗口在今日小组件隐藏且开启日常轻提醒时保留早安提示回退入口。
- （「拖延破冰」与「帮我准备」经 ADR-0049 裁定暂不引入。）

## 8. 外部 AI 接入（A7）

- 设置 → 助理 → 外部 AI 接入：总开关（默认关）、连接说明（一键复制配置）、最近访问记录。
- 外部写入后主窗口出现 Toast「由 <工具名> 添加 3 项 · 撤销」。
- 删除、批量改期必须在 Plana 内确认；Plana 未运行时，外部 AI 得到明确提示而不是静默失败。

## 9. 验收清单

- [x] 助理未打开：常驻启动路径不加载 `VGList.Agent` / `VGList.Mcp`（已通过隔离断言单测）。
- [x] 无模型配置时助理面板显示引导；自然语言日期仍可用。
- [x] 应用 → 全窗口 ≤ 1s 同步；撤销恢复到应用前且仅影响该变更集（含单条 / 多选 / 整批撤销）。
- [x] 违反规则的条目标红并给出原因；「删除」默认需确认（可在设置调整）。
- [x] 记忆/画像文件可直接用文本编辑器打开；清空后助理不再引用。
- [x] 早安提示入口可用（仅首次启动且有逾期任务时展示，支持小组件与主窗口回退，可在设置关闭）。
- [x] 外部 AI 开关默认关；关闭时外部连接被拒绝；开启后经当前用户专属命名管道接入，支持只读/读写、限流、删除与批量改期确认、脱敏审计与撤销。
