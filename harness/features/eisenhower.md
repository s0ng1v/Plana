# 四象限页 · P0 规格

状态：implementing（2026-11-19）
更新时间：2026-11-19
对应 product.md：P0 第 4 页「四象限页」

## 1. 布局与映射规则

- 头部（高 44）：等分 `!` 四象限图标 + `四象限`（20 SemiBold）+ 范围切换胶囊（`全部` | `仅今天`）；去掉无意义副标题。
- 主体：2 × 2 等分网格（间距 12px，左右外边距 20px），四张圆角 12 卡片（`Main.Bg` 底、`Main.Border.Subtle` 描边）：
  1. **重要且紧急** ← `TaskPriority.High`（标题与 `!` 徽标同用 `Priority.High`）
  2. **重要不紧急** ← `TaskPriority.Medium`（标题与 `!` 徽标同用 `Priority.Medium`）
  3. **不重要但紧急** ← `TaskPriority.Low`（标题与 `!` 徽标同用 `Priority.Low`）
  4. **不重要不紧急** ← `TaskPriority.None`（标题与 `!` 徽标同用 `Priority.None`）

## 2. 卡片交互

- 每张卡片顶部含 `!` 徽标 + 同色象限名 + 未完成数徽章 + 悬停才显露的右上角 `＋` 按钮（去掉卡片副标题）。
- 点击 `＋` 弹出与日历同构的**悬浮快速新建卡片**（宽 348px；预置当前象限优先级，支持选日期、右上角优先级圆点 `Tab` 或点击切换、切换待办事项清单且空行支持 `Backspace`/`Delete` 删除该行、切换收集箱/欢迎清单）：右列象限（重要不紧急 / 不重要不紧急）向左侧延伸展开，左列象限向右延伸展开，点外部或 `Esc` 收起。
- 卡片内部独立纵向滚动：
  - 未完成任务按日期升序排列，复用 `TaskRowControl`（无备注横线图标、无悬停快捷操作胶囊，子待办饼图小号且与文字上下居中）。
  - 底部提供折叠的 `已完成 (N)` 分组，默认收起。
  - 无任务时显示轻量象限空状态提示。
- 点击任意任务行在行旁弹出与日历/月历同构的**悬浮编辑卡片**（宽 348px）：左列象限向右伸出，右列象限向左伸出，点外部或 `Esc` 收起；卡片内可修改标题、描述/待办事项、优先级（修改后任务立即归入新象限）、日期、清单或删除。不再使用右侧 360px 抽屉。
- 严格遵循 P0 边界：暂不做跨象限拖拽改优先级（属 P1）。
