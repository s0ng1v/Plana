# 主窗口壳层与任务页 · P0 规格

状态：implementing（2026-11-18，UI 与功能重构版）
更新时间：2026-11-19
对应 product.md：P0 第 3 页「任务页」及主窗口壳层

## 1. 范围

本期交付重构后的主程序壳层与完整任务页（并接入四象限页、日历页、设置页）：

- **壳层**：扩展客户区浅色窗口（40px 顶部工具条，右侧安全避让系统标题按钮）+ 左侧 64px 图标栏 + 可折叠 248px 清单栏 + 主内容区 + 底部浮动撤销提示条（Toast）。
- **任务页**：视图切换（今天 / 最近7天 / 收集箱 / 自建清单 / 已完成）、排序（默认 / 优先级 / 日期）、可折叠日期分组、已过期「顺延到今天」、增强型行内添加（优先级/日期/清单快捷选择）、带完成动效与悬停快捷操作的 `TaskRowControl`、平滑滑入的右侧 `TaskDetailPanel`。
- **生命周期与同步**：主窗口为主程序生命周期主体，关闭即退出进程并关闭小组件；通过 `WidgetCoordinator` 在设置页管理小组件显隐、透明度、置顶与位置重置；所有视图共享同一 `ITaskRepository`。

## 2. 窗口与顶部工具条

| 项 | 值 |
|---|---|
| 基准尺寸 | 1104 × 706（最小 1004 × 620） |
| 标题栏 | `WindowDecorations=BorderOnly`、`ExtendClientAreaToDecorationsHint=True`，标题栏高 40；自绘紧贴窗口右上角（0px 右边距）的 46×40 Win11 风格最小化 / 最大化还原 / 关闭按钮，左侧交互控件留足右侧拖动区 |
| 顶部工具条 | 左侧：清单栏折叠/展开按钮（任务页可用）、今日日期与农历摘要；不显示额外进度徽标；中间空白拖动与双击最大化 |
| 主题 | Plana（粉紫蓝，默认）或经典蓝白（`ClassicBlue`），设置页可切换并持久化；两者均为浅色主窗 + 深色小组件 |
| 窗口图标 | `Assets/Plana/plana.ico`，任务栏与 Alt+Tab 显示 Plana 官方图标 |

## 3. 壳层布局与过渡

```
64px 图标栏 | [可折叠 248px 清单栏 + 1px 分隔] | 主页面（任务页 = 弹性列表 + 可拖拽分割线 + 详情面板；或四象限 / 日历 / 设置）
```

- **左侧图标栏（64px，`Main.Rail`）**：
  - 顶部品牌区：`36×36` Plana 官方图形（`Assets/Plana/plana-mark.png`）+ 46px 宽官方字标（`plana-wordmark.png`），静态无动效；点击返回「任务页」。**禁止重绘或改造 Logo，必须使用设计稿导出的资源。**
  - 导航项 40×40 圆角 10，内嵌 20×20 精绘矢量图标（`Stretch=Uniform` 抗锯齿对齐）：任务（`Ctrl+1`）、四象限（`Ctrl+2`）、日历（`Ctrl+3`）；选中项采用 `Main.Accent.Soft` 柔底 + `Main.Accent` 图标（不加孤立外置竖条）。
  - 细分隔线下方：宠物 IP 助理入口（42×42 圆角 12，内嵌 `42×42` Skia 自绘 `LanaAvatarControl`，Sleep / Idle / Listening / Thinking / Happy 五态与悬停唤醒，选中柔紫底 + 描边，`Ctrl+4` / `Ctrl+J` 切换独立对话页，见 ADR-0066；对话页欢迎主视觉与消息头像仍使用 `Assets/Plana/plana-pet.png`）。
  - 底部：设置（`Ctrl+,`，精绘滑块调整矢量图标）。
- **可折叠清单栏（248px → 0px，180ms 过渡）**：
  - 支持点击顶部栏图标或 `Ctrl+B` 平滑收起/展开，放大列表与详情操作空间。
  - 视图项高 38、圆角 8：今天 / 最近7天 / 收集箱，分隔后「清单」分组（由仓储动态渲染，首项为示例清单「欢迎」），底部固定「已完成」。
  - 「清单」分组规则：每项显示彩色圆点、清单名与未完成计数，点击切换到该清单；分组末尾固定「＋ 新建清单」入口；右键清单可「重命名」（行内输入框，`Enter` 提交 / `Esc` 取消 / 失焦提交）或「删除清单」（其中的任务自动移入收集箱，删除后 Toast 提示）；收集箱不可重命名或删除。
- **页面切换过渡**：
  - 切换主页面（任务 ↔ 四象限 ↔ 日历 ↔ 设置）或任务视图时播放 180ms 淡入 + 8px 轻位移（尊重「减少动画」设置）。
- **可调分栏**：
  - 任务列表（最小 340px）与详情面板（默认 380px，最小 320px）之间支持 `GridSplitter` 微调宽度。

## 4. 任务页功能与交互

### 4.1 头部与排序
- 左：视图图标（20×20 线性圆角方块 + 对勾，圆角 4.5、描边 1.5 `Main.Accent`）+ 标题（20px SemiBold）+ 未完成数徽章；右：排序切换胶囊（默认 / 优先级 / 日期）+ `＋` 快捷聚焦输入框按钮。

### 4.2 增强行内添加框（与今日小组件同形态）
- 默认高 42、圆角 10、`Main.Input` 底；聚焦后切白底 + `1.5px` 边框，边框色即当前草稿优先级（低=蓝 / 中=黄 / 高=红 / 无=中性灰）。
- 多行录入：`Enter` 提交、`Shift+Enter` 换行；随内容自动增高（上限 132，超出内部滚动）。
- 单行时整行内容（加号 / 文本 / 日期按钮 / 清单下拉）在录入框内垂直居中；多行时回到顶部对齐，日期按钮与清单下拉一起下放到第二行、同排右对齐。
- 日期按钮内日历图标与文字共用同一视觉包围盒并垂直居中（图标几何在 14×12 内上下对称，不产生 1px 下坠）。
- 优先级不再独立成 pill，改由输入框内部呈现（与今日小组件一致）：
  - 占位文案三段式：未聚焦「添加任务…」；聚焦且未按 Tab「按Tab切换优先级」（中性色）；按过 Tab 后「低优先级 / 中优先级 / 高优先级 / 无优先级」，占位颜色跟随优先级语义色
  - 聚焦即默认低优先级（只体现在边框与占位上）；失焦还原为「无」
  - 输入期 `Tab` 循环：首次按直达「高」，之后 高→中→低→无→高
- 日期按钮与右侧常驻清单下拉统一为下拉框形态：圆角矩形（圆角 7、1px `Main.Divider` 描边、白底）+ 图标 + 文字 + 灰色下拉箭头，悬停背景转为 `Main.Hover`；点击分别弹出 `DatePickerPopover` 与清单菜单。
- 点击窗口内任意其他区域（含左侧清单栏、导航栏、右侧详情）即失焦，并收起选项与浮层。
- `Enter` 提交后清空文案；仍聚焦则从低优先级继续连续录入，否则优先级重置为「无」，保持已选清单/日期。

### 4.3 分组与任务行（`TaskRowControl`）
- 分组标题支持点击折叠/展开，左侧箭头 150ms 平滑旋转。
- 「已过期」分组右侧提供 `顺延到今天` 按钮，一键将当前视图内全部逾期未完成任务改期为今天，并触发撤销 Toast。
- `TaskRowControl`（高 44、圆角 8）：
  - 选中态左侧带 3px `Main.Accent` 指示条 + `Main.Selected` 底色。
  - 复选框 18×18 圆角 5，描边跟随优先级；hover 放大 1.12 倍；勾选时播放对勾弹出与删除线生长动画后写回仓储（已完成项点勾直接恢复）。
  - 标题右侧仅在任务存在子待办时显示小号且与左侧中文文字上下光学居中的饼状进度图标（不显示冗余的备注横线图标）；右侧仅显示清单标签与语义色日期（去除悬停快捷操作胶囊，保持任务页与四象限行视觉纯净）。
- 列表为空时只保留居中标题与副标题，不再显示线稿图标与「立即添加一条任务」按钮。

### 4.4 详情面板（`TaskDetailPanel`）
- 位于顶部 40px 工具条之下，再也不与系统关闭按钮重排。
- 未选中时显示精致线稿空状态 + 快捷键速览（`Ctrl+N` 新建、`Ctrl+B` 折叠侧栏、`Esc` 取消选择）。
- 选中任务时播放 180ms 淡入 + 轻滑入：
  - 顶部条（高 48）：18px 复选框 · 竖分隔 · 日期 chip（弹窗支持今天/明天/后天/下周与 6×7 农历日历，补齐非本月 0.4 透明度）· 弹性 · 优先级胶囊按钮（点击弹出 4 档优先级选择菜单）· 关闭 `×`。
  - 标题：20px SemiBold，`TextWrapping="Wrap"` 支持长标题完整展示，失焦或 `Enter` 提交；空标题自动还原。
  - 描述与待办事项区：支持多行纯文本或一键切换为可勾选待办清单（`Enter` 换行添项、空行 `Backspace` 删除并上移焦点，也可随时在清单与多行文本间双向转换）；底部显示创建日期与字数/进度统计。
  - 底部条：清单切换 chip（弹出全部清单菜单，圆点 + 名称 + 当前项对勾）· 弹性 · 删除按钮（`Main.Danger.Soft` hover，删除后触发 4 秒撤销 Toast）。

### 4.5 浮动撤销 Toast 与快捷键
- 删除任务、批量顺延、日历拖拽改期后，底部居中滑入深色胶囊提示条（`ToastBanner`，4 秒自动收起），点击「撤销」立即恢复原状态。
- 全局快捷键：`Ctrl+1/2/3/,` 切页、`Ctrl+B` 折叠清单栏、`Ctrl+N` 聚焦新增、`Esc` 依次关闭弹层/取消选中/回到任务页。
