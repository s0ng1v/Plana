# 日历页 · P0 规格

状态：implementing（2026-11-18）
更新时间：2026-11-18
对应 product.md：P0 第 5 页「日历页」

## 1. 布局与视图

- 头部工具条（高 48）：
  - 左：日历标题（月视图 `2026年11月` / 周视图 `2026年11月 · 第47周`）+ `‹ 今天 ›` 切换按钮组。
  - 右：视图切换分段胶囊（`月` | `周`）；移除「显示已完成」开关与右上角「新建」按钮。
- 交互方式：日历页不再使用右侧详情栏；无论点击日期格新建还是点击已有任务修改，统一在目标旁弹出**宽敞型悬浮小卡片**（348px 宽）。

## 2. 月视图（6 × 7）

- 周日起始 7 列星期头 + 6 行自适应填满剩余高度的网格。
- 单元格左上公历日号（某月 1 日含月名；普通单天今天为 `22×22` 正圆实心圆 + 光学居中数字 + `Main.Calendar.TodayTint` 微底），右上农历/节气/节日（节日/节气 `Calendar.Festival` 绿色），悬停右上显露 `＋` 新建按钮。
- 单元格内按高度展示多条任务芯片（纯色优先级柔底 `Main.Eisenhower.*.Soft`，不加左侧竖线 + 可点击迷你复选框 + 标题 + 含子待办时的饼状进度图标），超出部分显示 `+N 更多`（点击打开窗内当日任务列表浮层）。
- **悬浮新建 / 编辑小卡片（348px 宽，正文/待办区最小高 124px）**：
  - 点击单元格空白或 `+` 在单元格旁弹出**悬浮新建卡片**；点击任意已有任务芯片在芯片旁弹出同构的**悬浮编辑卡片**（顶部左侧含任务完成复选框 + 竖分隔 + 日期按钮，右侧为**优先级圆点**而非旗帜；中部为标题 + 待办清单切换按钮 + 多行描述/待办事项编辑区；待办事项空行按 `Backspace` 或 `Delete` 即可删除该行；底部为清单切换 + 子待办饼图进度 + 新建态「添加」按钮 / 编辑态「删除」按钮，编辑态所有改动实时写回仓储）。
- **拖拽改期**：按住并拖动任意任务芯片移动超过 6px 触发拖拽态（跟随指针浮动预览胶囊），经过目标日期格时高亮 `Main.Accent.Soft` + `Main.Accent.Border`，释放后立即更新 `task.Date` 写入共享仓储并弹出「已改期到 M月d日 · 撤销」Toast。

## 3. 周视图（7 列）

- 展示当前周（周日至周六）7 个纵向列，每列头显示 `周X` + 大号日号 + 农历，及该日快速 `＋` 按钮。
- 列内纵向排列任务卡片（完整标题、复选框、清单名与描述摘要），支持独立滚动与空列引导。
- 同样支持点击新建、点击任务弹出悬浮编辑小卡片与跨列拖拽改期。
