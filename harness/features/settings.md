# 设置页 · P0 规格

状态：implementing（2026-11-18）
更新时间：2026-11-18
对应 product.md：P0 第 6 页「设置页」

## 1. 布局（ADR-0045 更新）

- 左侧 196px 二级分类导航（`Main.Surface.Subtle` 底 + 1px `Main.Divider`）+ 右侧独立子页（切页 160ms 淡入上滑）：
  1. **常规与外观**
     - 主题配色：`Plana 淡粉`（默认，淡粉樱雾）与 `经典蓝白` 两个选项，各带圆形色样；点击即时切换全部窗口并持久写入 `settings.json` 的 `Main.Theme`
     - 「减少界面动效」开关（关闭/大幅缩短主窗口过渡动画、对话渐入与 SSE 文字渐入，并持久写入 `settings.json`）
     - 「自动识别日期」开关（默认开；输入框离线识别中文日期，见 A1）
     - 内置中文日历说明（1901–2100 农历 / 24 节气 / 公农历节日，完全离线）
     - 快捷键速查列表（`Ctrl+1/2/3/4`、`Ctrl+J`、`Ctrl+,`、`Ctrl+B`、`Ctrl+N`、`Tab`、`Esc`）
     - 「重置为示例数据」按钮（二次确认，写入可撤销变更集，见 A0）
  2. **模型服务**（独立完整子页，详见 [model-settings.md](./model-settings.md)）
     - 当前使用状态条 + 搜索/分类筛选 + 20 家官方 Logo 厂商卡片网格 + 自定义模型 + 右侧滑入配置抽屉。
  3. **桌面小组件**（通过 `WidgetCoordinator` 实时联动桌面小组件窗口与 `SettingsStore`）
     - **通用行为**：「显示桌面时保持可见」开关（默认开；Windows 下点击右下角「显示桌面」或按 `Win+D` 时不隐藏桌面小组件，可随时关闭，ADR-0073）。
     - **今日日程小组件**：显示/隐藏开关、置于顶层开关、背景不透明度滑块（40–100%）、显示添加框开关、显示已完成开关、「重置位置与尺寸」按钮。
     - **月历小组件**：显示/隐藏开关、置于顶层开关、背景不透明度滑块（40–100%）、显示农历与节日开关、显示已完成开关、「重置位置与尺寸」按钮。


## 4. 模型服务（助理阶段，详见 [model-settings.md](./model-settings.md)）

设置页新增「模型服务」分组：厂商卡片网格 + 配置抽屉 + 自定义。「测试连接」通过才可设为当前使用。助理面板与模型服务未配置时显示引导「先配置模型」。
