# 术语表

状态：agreed（2026-11-17）
规则：文档、代码、UI 文案必须使用本表用词，禁止同义词混用。

| 术语 | 英文/代码名 | 定义 | 易混点 |
|---|---|---|---|
| 任务 | Task | 一条待办，最小单位 | 不等于"清单" |
| 清单 | Project | 任务的容器，有名称、颜色、图标 | 不要叫"列表" |
| 收集箱 | Inbox | 默认清单，无归属任务落这里 | 是清单的一种，不是独立概念 |
| 列表 | List | 界面上的任务集合呈现，不是数据实体 | 不要与"清单"混用 |
| 今天 | Today | 到期日 ≤ 今天且未完成的任务集合 | 不是"今天创建" |
| 最近 7 天 | Next7Days | 今天起 7 天内到期的任务集合 | — |
| 优先级 | Priority | 无 / 低 / 中 / 高，四档 | 不是四象限的"重要/紧急" |
| 四象限 | Eisenhower | 按优先级一对一映射的四宫格视图 | 不许单独维护重要/紧急字段 |
| 子任务 | ChecklistItem | 任务下的检查项 | 不是独立任务，不进主列表 |
| 小组件 | Widget | 独立无边框常驻窗口 | 不是主窗口里的面板 |
| 贴桌面 | DesktopPinned | 通过 WorkerW 挂到桌面层，被普通窗口遮挡 | 与"置顶"相反 |
| 置顶 | AlwaysOnTop | 始终浮于其他窗口之上 | — |
| WidgetHost | — | 管理小组件窗口生命周期、拖动、缩放、层级 | 不是某个具体小组件 |
| 草稿态 | Draft | 输入框中尚未提交的内容及其优先级/日期 | 不是任务 |
| 已完成分组 | CompletedGroup | 列表或卡片内折叠的已完成任务区 | — |
| 主窗口 | MainWindow | 应用主界面 | — |
| 详情面板 | TaskDetailPanel | 主窗口右侧的任务详情区 | 小组件用的是"详情小窗" |
| ASSET | — | 见 harness/assets/ | — |
| 助理 | Assistant | 主窗口内的 AI 对话面板，只提方案，不直接改数据 | 不等于「小组件」 |
| 提案 | Proposal | 助理给出的一组待应用改动（新增/改期/改字段/删除） | 未应用前不进仓储 |
| 幽灵预演 | GhostPreview | 把提案以半透明形式叠加在当前页面上 | 只读，不可交互编辑数据 |
| 变更集 | ChangeSet | 一次写入产生的全部改动，可整批撤销 | 用户、助理、外部 AI 都产生变更集 |
| 我的规则 | MyRules | 用户给助理定的排期硬上限、偏好、权限分级 | 个人 Harness 的产品名 |
| 记忆 | Memory | 助理记住的单条长期信息 | 不是对话历史 |
| 画像 | Profile | 由记忆与完成情况汇总的「Plana 眼中的你」可编辑文档 | — |
| 模型服务 | ModelProvider | 厂商预设或自定义的 API 配置 | 与「清单」无关 |
