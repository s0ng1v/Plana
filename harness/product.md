# 产品共识

状态：agreed（2026-11-17）
更新时间：2026-11-17
依赖：[blueprint.md](./blueprint.md)

## 1. 定位

本地优先的轻量桌面任务软件，首发 Windows。核心承诺：把「今天要做什么」放在桌面上，一眼可见、一键可改。

- 目标用户：需要桌面常驻待办视图、重视效率与视觉质感的个人用户。
- 非目标（P0）：团队协作、习惯打卡、番茄专注、笔记体系、云端账号。

## 2. P0 页面清单与施工顺序

| 顺序 | 页面 | 关键内容 |
|---|---|---|
| 1 | 今日日程小组件 | 独立窗口、添加任务输入框、优先级快捷条、日期 chip、已完成分组 |
| 2 | 月历小组件 | 年月标题、翻页、今天、周日起 6×7、农历/节气/节日、任务 chip 与 `+N` |
| 3 | 任务页 | 左栏 + 列表 + 右侧详情面板 + 行内添加 |
| 4 | 四象限页 | 2×2 卡片、按优先级映射、今天/已完成分组、卡片内滚动 |
| 5 | 日历页 | 月视图 + 周视图、点击新建、拖拽改期 |
| 6 | 设置页 | 外观 / 小组件 / 通用 |

顺序理由：两个小组件共用 WidgetHost 与设计令牌，集中做完最省；任务页提供任务行与详情两个基础组件；四象限复用任务行；日历最复杂放最后。

## 3. 功能边界

### P0 范围内

- 任务：新增、编辑、完成/取消、删除、优先级（无/低/中/高）、日期、清单归属、子任务（只读展示可后置）。
- 视图：今天、最近 7 天、收集箱、清单、已完成。
- 小组件：今日日程 + 月历，支持拖动、缩放、贴桌面、位置记忆。
- 日历：月、周两种视图。
- 四象限：固定按优先级映射，卡片内 `+` 新建带默认优先级。

### P1（首批立项落地，ADR-0053）

- **重复任务**：每天 / 工作日 / 每周 / 每月 / 每年 / 农历每年；完成时在同一可撤销变更集内生成下一期。
- **回收站**：删除先软删进入回收站（默认保留 30 天），支持单条恢复、彻底删除与一键清空。
- **标签与筛选器**：任务支持多 `#标签`（输入框行内识别 + 详情页增删），任务页提供按标签与重复任务的快捷筛选栏。
- **四象限跨卡片拖拽改优先级**：按住四象限任务行跨象限拖放即可变更优先级，带落点高亮与撤销。
- **数据导入 / 导出备份**：支持 JSON 完整备份、Markdown 清单与 RFC 5545 `.ics` 日历导出与导入（导入支持整批撤销）。
- **开机自启动 & 小组件锁定 / 点击穿透**：Windows 注册表用户级开机自启（可选静默进托盘）、小组件位置尺寸锁定与鼠标点击穿透（含托盘应急解除）。
- **日程时间与 Windows 原生通知提醒（ADR-0055）**：任务支持具体时间（`HH:mm`）与提前任意时间提醒（默认提前 10 分钟），支持按间隔反复提醒，到点通过 Windows 原生通知提醒；支持 Lana 自动识别设置及在卡片 / 任务详情中手动调整。

（其余 P1 候选如日历其余视图、评论/模板暂保持后置。）

### P2

同步服务端、手机端、账号体系、共享清单。

## 4. 产品级约定

1. 「今天」是全局核心口径：主窗口首项、小组件标题、日历高亮、四象限分组都以它为准。
2. 优先级是四象限的唯一数据源，不额外维护「重要/紧急」布尔字段。
3. 未完成复选框的描边色跟随优先级：红/黄/蓝/灰；已完成统一为灰色填充 + 白色对勾 + 删除线。
4. 任务提交后输入框必须复位（清空、高度回落、优先级归无），避免连续录入误标。


## 5. 助理阶段（2026-11-21 立项，P0 收口后开工）

状态：planned。详细规格见 [features/assistant.md](./features/assistant.md) 与 [features/model-settings.md](./features/model-settings.md)，决策见 ADR-0042 / ADR-0043。

| 序 | 模块 | 一句话 |
|---|---|---|
| A0 | 本地持久化 + 变更撤销 | 任务落 SQLite；任何写入形成可整批撤销的变更集 |
| A1 | 中文自然语言日期 | 输入框直接听懂「下周三」「月底前」，离线、不耗 Token |
| A2 | 模型服务配置 | 厂商预设卡片只填 Key，也可自定义 URL |
| A3 | 助理内核 | 对话、工具、提案、权限分级、中文历法工具 |
| A4 | 助理面板 + 幽灵预演 | 右侧面板、附件输入、预览后应用、`Ctrl+Z` 撤销 |
| A5 | 我的规则 + 记忆画像 + 周复盘 | 个人排期铁律、本地可读可改的记忆与画像 |
| A6 | 日常小帮手 | 早安提示、拖延破冰、「帮我准备」 |
| A7 | 外部 AI 接入 | 允许 Claude / Cursor / Antigravity 等读写 Plana |

非目标（助理阶段内）：桌面截屏/剪贴板全局捕获、语音输入、云端同步、账号、任何遥测。文件与图片输入限于「拖入/粘贴到助理面板」。
